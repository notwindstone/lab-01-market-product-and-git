## Roles and responsibilities

- UI/UX Designer
  - Design wireframes, interactive prototypes, and high-fidelity mockups (using Figma/Sketch).
  - Establish and maintain design systems for consistency across apps/websites.
- Software Engineer (iOS/Android)
  - Develop, test, and maintain native/hybrid mobile apps (Swift/Kotlin).
  - Integrate REST/GraphQL APIs and implement offline functionality.
  - Adhere to App Store/Play Store guidelines.
- SEO Specialist
  - Perform keyword research, on-page optimization (meta tags, headers, schema markup), and technical audits.
  - Optimize SSR framework output (Next.js/Nuxt) for crawlability, speed (Lighthouse), and mobile responsiveness.
- Software Engineer (Cross-platform)
  - Build/maintain pickup point kiosk software using frameworks like Flutter, React Native, or Electron.
  - Implement hardware integrations (barcode scanners, printers), offline sync, and real-time status updates.
  - Ensure cross-OS compatibility (Windows, Linux, Android).
- Data Analyst
  - Extract, clean, and analyze operational data (inventory turnover, processing times, error rates).
  - Identify bottlenecks via statistical analysis; recommend process optimizations.
